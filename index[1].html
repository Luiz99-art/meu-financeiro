Importar extrato CSV

Importação local de arquivo CSV simples com cabeçalho: data,descricao,valor,tipo,categoria,forma,estabelecimento. Exemplo de data: 2026-11-02; valor: 125.50; tipo: despesa ou receita.

CSV é o formato de extrato disponível. Para anexar fotos de notas fiscais, entre na aba Lançamentos. A leitura automática de textos por foto ainda não está disponível.

Seus dados e backup

Os dados ficam neste navegador neste dispositivo. Não existe conexão bancária nem sincronização automática nesta versão. Faça backup para não perdê-los.

O backup inclui os comprovantes anexados, caso o navegador permita acessá-los. Confira o tamanho do arquivo e guarde em local seguro. Para transferir dados, exporte o backup e restaure no outro aparelho. Isso substitui os dados no destino, não mescla mudanças.
